# Changelog

## v0.1.0 — Core & Demo (planned)

The first public release focuses on a privacy-safe, local-first core.

- Includes SQLite schema, metrics, semantic-analysis interfaces, MCP integration and a synthetic preview.
- Does not bundle chat archives, private datasets, model weights, WCD, or WeFlow.
- WCD and WeFlow remain optional local data providers.
- The preview runs without credentials, a provider, or personal data.

## Unreleased

- Contributor onboarding, templates and public visual assets.
