# Tools Misc 其他杂项

## 概述

其他杂项工具集，包括联系人列出、目录浏览、批量解压、标点检查等。

## 文件列表

| 文件 | 职责 | 使用场景 |
|------|------|---------|
| `list_contacts.py` | 列出联系人 | 列出所有联系人 |
| `list_second_level.py` | 列出二级目录 | 列出二级目录内容 |
| `batch_zip_extract.py` | 批量解压 ZIP | 批量解压 ZIP 文件 |
| `punctuate_check.py` | 标点检查 | 检查标点使用 |
| `punctuate_docs.py` | 文档标点处理 | 处理文档标点 |

## 使用示例

```bash
# 列出联系人
python tools/misc/list_contacts.py

# 列出二级目录
python tools/misc/list_second_level.py

# 批量解压 ZIP
python tools/misc/batch_zip_extract.py

# 检查标点
python tools/misc/punctuate_check.py
```
