# Formulas 战态公式

## 概述

`formulas/` 存放 Agent 的**战态公式定义**，包括 IVI（意图真实度）、SPE（社交势能）、EWS（升温窗口期）等 9 个公式。公式是辅助参考视角，核验而非套用，阈值是参考不是硬规则。

## 公式列表

| 公式 | 工具 | 含义 | 范围 |
|------|------|------|------|
| IVI | `formula_calc_ivi` | 意图真实度（Interest Veracity Index） | 0-1 |
| SPE | `formula_calc_spe` | 社交势能（Social Potential Energy） | 0-1 |
| EWS | `formula_calc_ews` | 升温窗口期（Escalation Window Score） | 0-1 |
| IS | `formula_calc_is` | 真实亲密度（Intimacy Score） | 0-1 |
| Gap_Effect | `formula_calc_gap_effect` | 情绪落差刺激 | -1~1 |
| EEV | `formula_calc_eev` | 升温期望值（Escalation Expectation Value） | 0-1 |
| CS | `formula_calc_cs` | 矛盾演化状态（Contradiction State） | -1~1 |
| Action | `formula_calc_action` | 终极行动决策 | 进攻/拉扯/重置/维持 |

## 公式详解

### IVI（意图真实度）

衡量对方表达的兴趣是否真实。

**输入参数**：
- fback（回复字数比）
- fback_quality（回复质量）
- qscore_personal（个人化问题比例）
- rlatency（回复速度比）

**计算逻辑**：综合考虑回复质量和速度，排除敷衍式回复。

### SPE（社交势能）

衡量对方在社交互动中的势能状态。

**输入参数**：
- 消息量
- 活跃天数
- 朋友圈互动

**计算逻辑**：基于活跃度和互动频率计算。

### EWS（升温窗口期）

判断当前是否适合推进关系。

**输入参数**：
- composite（综合指标）
- trend（趋势）
- recent（最近消息时间）

**计算逻辑**：综合指标 + 趋势 + 时效性判断。

### IS（真实亲密度）

衡量双方真实的亲密程度。

**输入参数**：
- 聊天深度
- 个人化话题比例
- 情绪共鸣

### Gap_Effect（情绪落差刺激）

衡量忽冷忽热策略的效果。

**输入参数**：
- 回复速度波动
- 消息量波动

**计算逻辑**：波动越大，情绪落差刺激越强。

### EEV（升温期望值）

计算推进关系的预期成功率。

**输入参数**：
- EWS（升温窗口期）
- IVI（意图真实度）
- IS（真实亲密度）

**计算逻辑**：综合窗口期、意图真实度、亲密度。

### CS（矛盾演化状态）

判断关系中的矛盾状态。

**输入参数**：
- 情绪波动
- 回复质量波动
- 互动频率波动

**计算逻辑**：正向为和谐，负向为矛盾。

### Action（终极行动决策）

基于所有公式给出最终行动建议。

**输出**：进攻 / 拉扯 / 重置 / 维持

## 公式使用原则

1. **辅助参考**：公式结果是参考视角，不是决策依据
2. **阈值参考**：公式阈值是参考，不是硬规则
3. **Wiki核验**：公式结果必须用 Wiki 知识核验
4. **一次出现**：公式数值只在"数据全貌"表中出现一次
5. **不主导策略**：策略建议必须基于 Wiki 知识，不是公式数值
