# 案例：窗口降温——连续错过邀约后，怎样重新给出行动反馈

> 完全合成的教学案例。人物、消息、地点、数字和时间顺序均经过重写与区间化；不对应任何单一真实对话。

## 问题

用户和小岚认识不久。小岚两次提到“周末想去 xx 公园走走”“附近新开了一家咖啡店”，用户都表示感兴趣，却都因临时安排没有落实。聊天没有立刻中断，但从自然延续变成“想到才回一句”。

这既不是“她突然不喜欢了”，也不是“还在聊天就仍有窗口”。连续两次主动提出共同活动却没有收到行动反馈，才是值得复核的事件。

## 脱敏后的互动切片

| 阶段 | 重新写作后的片段 | 可观察到的事实 |
|---|---|---|
| 第一次尝试 | 小岚：“xx 公园的湖边应该挺舒服。” 用户：“听起来很好，不过这周赶不上。” | 对方主动把话题带向共同体验；没有替代时间 |
| 第二次尝试 | 小岚：“那家店的甜点看起来不错。” 用户：“我也想去，最近事情有点多。” | 再次出现行动信号；仍没有可执行回应 |
| 降温后 | 小岚：“今天路过那边。” 用户：“哈哈，下次俺也去。” | 互动友好，但不再出现具体邀请 |

## 系统拆解

| 观察维度 | 区间化结果 | 应如何解释 |
|---|---|---|
| 邀约相关行为 | 前半段连续出现，后半段消失 | 行动信号变少，比消息量更值得复核 |
| 消息动量 | 从稳定转为间歇 | 双方都开始等待对方行动，不等于关系结束 |
| 话题延续 | 日常话题仍能接住 | 连接未断，不等于窗口仍和此前一样宽 |
| 事件记录 | 两次未落地的邀约 | 应进入事实档案，不能被平均分淹没 |

## 推理过程

1. 区分“提到地点”和“提出共同前往”；后者需要更高投入。
2. 区分礼貌性同意与可执行回应。替代时间、地点或下一步，才是行动反馈。
3. 不用长篇解释填补失约；解释不能替代行动。
4. 只做一次小而清晰的验证，不追问、不施压。

> “前两次你提到出去，我都没安排好，确实有点可惜。这个周末下午或下周晚上，你更想去 xx 公园散步，还是喝杯咖啡？最近不方便也完全没关系。”

| 后续反馈 | 合理更新 |
|---|---|
| 选择时间或主动给替代时间 | 继续落实一次具体活动 |
| 近期忙，但给出明确替代窗口 | 保持轻量联系，等对方给出的窗口 |
| 礼貌回应且不提供替代方案 | 降低追问频率，按普通关系维护 |
| 明确拒绝 | 接受拒绝，不用指标反驳 |

## 案例要点

- `semantic_invitation` 与事件记录识别行动窗口，不只统计聊天字数。
- 建议是一项可证伪的行动，不是“喜欢/不喜欢”的结论。
- 拒绝、沉默或替代安排都是完整信息，应该被尊重。
