# Public case studies

这里是 LoveMentor 的公开演示案例。它们用于说明分析流程和输出结构，不是用户数据样本。

## 脱敏原则

- 不提交原始聊天记录、截图、联系人姓名、微信号、手机号、邮箱或地理位置。
- 不保留可回溯到个人的精确日期、时间线、学校、单位、旅行安排和关系细节。
- 对话片段使用重新撰写的占位文本；指标使用区间化或示意值。
- 案例由多个本地分析结果中的模式合成，不能反推出任何单一真实案例。

## 推荐阅读顺序

1. [窗口降温：主动邀约没有被接住](window-cooling.md)
2. [朋友信号 ≠ 浪漫信号](friend-signal-vs-romantic.md)
3. [冲突修复：先处理边界，再谈升温](boundary-repair.md)

如果你要把自己的分析结果发布到仓库，建议只保留“输入类型 → 可观测信号 → 方法论 → 建议”的链路，并在发布前对整个文件做隐私扫描。
