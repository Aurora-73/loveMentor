# Public case studies

这里是 LoveMentor 的公开演示案例。它们用于说明分析流程和输出结构，不是用户数据样本。

## 脱敏原则

- 不提交原始聊天记录、截图、联系人姓名、微信号、手机号、邮箱或地理位置。
- 不保留可回溯到个人的精确日期、时间线、学校、单位、旅行安排和关系细节。
- 场景可以保留为“xx 公园”“某城市的咖啡店”“共同兴趣群”等通用描述；不保留可搜索或可组合定位的地点、组织、课程、路线和活动信息。
- 对话片段全部重新写作；指标使用区间、相对变化或示意值，不发布原始记录。
- 案例从多个本地分析结果的共同模式中提炼，不能反推出任何单一真实案例。
- 角色固定标记为“用户”和一个任意化的对方称呼（如“小岚”）；“用户”始终是被分析、接收建议的一方。
