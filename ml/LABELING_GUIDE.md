# 对话行为标注指南

> 写给 Agent 的标注标准。标注方法适用于当前 2099 条微信对话窗口的完整集合。

---

## 一、任务描述

输入一段微信聊天记录（约 20 条消息），你需要对「她」的 10 个行为维度各打一个 **0-9 的整数分**。

对话格式示例：
```
[我] 嗯呢
[她] 你咋私聊
[我] 我问一下wiki
[她] 屎一样 要是你 你咋会
```

---

## 二、输出格式

每段对话标注后，输出 10 个整数，用 `|` 分隔：

```
7|8|6|1|5|5|3|7|6|1
```

---

## 三、标签定义与评分标准

### 标签顺序（严格按此顺序输出）

| 序号 | 标签 | 含义 |
|------|------|------|
| 1 | information_exchange | 她陈述事实信息 |
| 2 | opinion_expression | 她表达观点或评价 |
| 3 | emotion_positive | 她表现出正向情绪（开心、兴奋、温暖、撒娇） |
| 4 | emotion_negative | 她表现出负向情绪（生气、沮丧、焦虑、冷漠） |
| 5 | flirt | 她有暧昧、调侃、挑逗或撒娇 |
| 6 | question_asking | 她主动提问 |
| 7 | self_disclosure | 她主动分享个人信息、感受、经历 |
| 8 | invitation | 她邀约或积极回应邀约 |
| 9 | framing_boundary | 她使用关系框架词汇（哥/弟/姐/妹/老师/朋友等） |
| 10 | perfunctory | 她敷衍回应（单字、不延续话题、机械回复） |

### 评分锚点（所有标签通用）

| 分数 | 含义 | 典型场景 |
|------|------|----------|
| **0** | 完全不存在 | 整段对话无此行为 |
| **1-2** | 极弱 | 勉强有 1 处若有若无的迹象 |
| **3-4** | 较弱 | 偶尔出现一两处，但非主要特征 |
| **5-6** | 中等 | 明确出现，频率或强度达到一般水平 |
| **7-8** | 较强 | 多次明显体现，是对话中的突出行为 |
| **9** | 极强 | 非常典型，几乎贯穿整段对话 |

### 评分核心公式

**频率 × 典型程度 = 分数**

- 频率高 + 典型 → 高分（如她连发了 5 条撩人消息）
- 频率低 + 典型 → 中等分（如只发了一条但非常经典的表白）
- 频率高 + 不典型 → 中等分（如发了一堆"嗯"但每条都加了表情，算不上真敷衍）
- 频率低 + 不典型 → 低分

## 四、各标签的判分细则

### 1. information_exchange（事实信息）

**是什么：** 她告诉对方一个可验证的事实。包括作息、地点、经历、知识、技能、数字等。

**典型表现：**
- "我大四了"、"我是湖南本地人"、"我八点上班"
- "这个泡芙是长沙那家的"、"你们计算机专业 996"
- 教对方具体操作步骤也属于信息交换

**判分：**
- 0：全程没提供任何事实
- 3-4：提了 1-2 个零散信息
- 5-6：讲了一两个比较详细的经历或知识点
- 7-8：大段讲解、长篇教学（如教拍照、教撩妹）
- 9：几乎整段对话都在传授大量信息

**注意：** 敷衍回答不算信息交换。表情包、语气词也不算。

---

### 2. opinion_expression（观点/评价）

**是什么：** 她表达主观判断、评价、态度。不需要客观正确，只要有立场。

**典型表现：**
- "屎一样"、"不行"、"好厉害"、"你很文艺"
- "我觉得长沙工资太低了"、"这个表情包好变态"
- 表达喜好："我喜欢吃甜的"、"我不喜欢逛"

**判分：**
- 0：全程没有主观判断
- 3-4：偶尔评价一两句
- 5-6：多次表达观点，有明确态度
- 7-8：意见贯穿整段对话，有强烈的价值判断
- 9：从头到尾在输出观点（比如一直在 diss 一个人或事）

**与 flirting 的区别：** 观点偏理性/评价性，flirting 偏暧昧/挑逗性。但如果她故意用反对意见来撩人（"你真笨"那种），可以两个都高。

---

### 3. emotion_positive（正向情绪）

**是什么：** 她表现出开心、兴奋、温暖、欣赏、满足。

**典型表现：**
- 大笑："哈哈哈哈哈哈"、"笑死我了"
- 积极表情：😊、❤️、[破涕为笑]、[爱心]
- 温暖话语："好可爱啊"、"喜欢喜欢"、"你今天真棒"
- 撒娇式开心："嘻嘻"、"嗯呢嗯呢"
- 期待感："好呀好呀"、"可以可以"

**判分：**
- 0：冷漠或完全中性
- 3-4：偶尔笑一两下
- 5-6：整体氛围轻松，时不时笑/，但没有特别高涨
- 7-8：连续大笑、热情洋溢、主动分享快乐
- 9：从头到尾极其开心兴奋（如热恋期聊天）

**注意：** 不看"我"的话，只看她。不是所有"哈哈"都是强正向——敷衍的"哈哈"算 perfunctory。

---

### 4. emotion_negative（负向情绪）

**是什么：** 她表现出生气、沮丧、焦虑、委屈、冷漠、厌烦。

**典型表现：**
- 直接表达："我累了"、"真烦"、"无语了"、"不想提"
- 冷暴力："…"、"哦"、"算了"（连续的）
- 攻击性："你有病吧"、"别烦我"
- 悲伤/创伤："他毁了我整个青春"、"那段婚姻真恶心"
- 焦虑："我好困"、"今天夜班"、"太累了"

**判分：**
- 0：全程无负面
- 3-4：有轻微抱怨或疲惫，很快过去
- 5-6：明确表达不开心，持续多条消息
- 7-8：愤怒或悲伤明显，或持续抱怨整段
- 9：创伤倾诉、激烈的负面爆发

**注意：** 日常累/困不算强负面（除非伴随抱怨）。区分"工作好累啊，不过吃顿饭就好了"（3-4）和"我真的受不了了"（7-8）。

---

### 5. flirt（暧昧/调侃/撒娇）

**是什么：** 她有超越普通朋友关系的互动。包括暧昧表达、身体相关话题、关系试探、吃醋、占有欲、撒娇。

**典型表现：**
- 直接暧昧："爱上我没"、"想你了"、"你亲我"
- 吃醋/占有："冷漠的男人"、"那不逗你了，逗别人去了"
- 撒娇："哥哥哥哥"、"帮我改论文嘛"
- 身体相关："你喜欢黑丝吗"、"腹肌照发来"
- 撩人挑衅："你眼光还蛮高嘛"、"我看你就是想当我女朋友"
- 大胆玩笑："好，赢了我要你在后湖裸奔"
- 称呼+关系语气："弟弟，你很文艺"、"宝宝"

**判分：**
- 0：纯普通朋友聊天，或纯事务性交流
- 3-4：有一两次轻微的调侃或俏皮话
- 5-6：明显的撒娇/挑逗，但不是主要基调
- 7-8：多次撩人，对话主基调就是调情
- 9：直接表达性暗示、恋爱意图，或从头撩到尾

**flirt 和 emotion_positive 的区别：** 
- flirting 有对象指向性（对他），positive emotion 只是一般开心
- 比如"哈哈哈哈我好开心"→ emotion_positive=7, flirt=0
- 比如"哈哈哈哈你好坏呀"→ emotion_positive=7, flirt=6

---

### 6. question_asking（主动提问）

**是什么：** 她主动向对方提问，表示对对方有好奇心或想延续对话。

**典型表现：**
- "你咋私聊"、"你多大呀"、"你们几点下班"
- "你知道吗"、"你觉得呢"
- "那是为什么呀"、"为什么不回我"

**判分：**
- 0：全程没问过任何问题
- 3-4：问了 1-2 个问题
- 5-6：问了 3-5 个，有延续对话的意图
- 7-8：连珠炮式提问，非常主动了解对方
- 9：几乎每条消息都是问题（面试式聊天）

**注意：** 反问不算（"不是吗"这种）。已经知道答案的追问也算。

---

### 7. self_disclosure（自我表露）

**是什么：** 她主动分享关于自己的信息、感受、经历、想法。不需要对方问。

**典型表现：**
- 个人经历："我之前学跳舞的"、"我考研没考上"
- 情感状态："我最近好累"、"我以前被伤过"
- 日常分享："我今天吃了泡芙"、"家里就我和猫了"
- 深度倾诉："那段婚姻毁了我的人生"

**判分：**
- 0：全程不聊自己，只问对方或事务性交流
- 3-4：简单提了几句个人情况
- 5-6：分享了一段经历或感受
- 7-8：详细讲述个人故事，有深度
- 9：整段对话几乎都在倾诉自己（如婚姻创伤倾诉）

**与 information_exchange 的区别：**
- self_disclosure 是关于**自己**的（"我是湖南人"=7分）
- information_exchange 泛指提供任何信息（"这个店在后湖"=5分，但不是 self_disclosure）
- 一个消息可以两个标签都高分

---

### 8. invitation（邀约）

**是什么：** 她主动约对方见面、一起做某事，或积极响应对方的邀约。

**典型表现：**
- 主动邀约："你方便吗接电话"、"要不要一起看电影"、"来听歌吗"
- 积极响应："好呀好呀"、"可以呀，周五咋样"、"我等你"
- 持续推动见面："你到哪了"、"我在门口等你"、"好的，四点见"
- 间接邀约："我经常去后湖"（给对方机会约）、"下次一起"

**判分：**
- 0：没有任何见面/一起做事的意图
- 3-4：隐约表达了"以后可以一起"但没有具体推动
- 5-6：明确邀请了一个活动或表示兴趣
- 7-8：主动发起邀约+推动落实（时间地点等）
- 9：极其主动地推动见面（连环催促、打电话、出门了）

**注意：** 如果对方约她，她只是"嗯嗯"回了，不算 invitation。得是她主动或积极推动。

---

### 9. framing_boundary（关系框架）

**是什么：** 她用特定称谓或说法来定义两人关系。包括称呼、角色定位、边界声明。

**典型表现：**
- 称呼："哥哥"、"弟弟"、"老大"、"兄弟"、"学弟"
- 框架词："朋友而已"、"就像哥哥一样"
- 边界声明："我不谈外地的"、"我不想试试"
- 角色定位："我是遵纪守法的好员工"、"我才是真正的佛系读研"
- 教师/导师框架："谢谢哥"、"孺子可教"

**判分：**
- 0：没有任何关系框架语言
- 3-4：偶尔用了某个称呼
- 5-6：多次使用特定称谓，或明确表达了一次关系边界
- 7-8：称谓贯穿整段对话，或反复强调关系边界
- 9：整段对话核心就是在讨论/界定两人关系

**注意：** 配合 flirting 时 framing 会更高（因为"哥哥"+"暧昧"是常见组合）。

---

### 10. perfunctory（敷衍）

**是什么：** 她给出简短、机械、不延续话题的回复，表明她不想聊或心不在焉。

**典型表现：**
- 单字回复："哦"、"嗯"、"行"、"OK"
- 机械回应："好的好的"（没有实际内容）
- 不延伸话题：对方说了很多，她只回一两个字
- 回避问题：对方提问，她故意绕开或给模糊答复
- 拖延/推脱："有空再说"、"不知道"、"…"

**判分：**
- 0：每句话都在积极延伸话题
- 3-4：偶尔有短回复，但整体还是投入的
- 5-6：持续敷衍（如连续 3+ 条单字回复），明显不想聊
- 7-8：几乎每条都是敷衍，对话靠对方撑着
- 9：整段对话她就是"哦/嗯/行"三连，完全不走心

**注意：** 真正的忙碌（一边做事一边回）也会有短消息，但通常会解释。微信聊天中有些短消息是正常的，不要过度标注。只有当敷衍**成为整体模式**时才给高分。

---

## 五、标注流程（我实际使用的方法）

### 步骤

1. **通读一遍对话** — 先用 20 秒扫完，了解整体基调和主要话题
2. **先打极端分** — 找出得分最高的 2-3 个标签和最保证是 0 的标签
3. **再逐个判断** — 从第 1 到第 10 个标签，各给一个 0-9 的分数
4. **5 秒复查** — 看看有没有明显不对劲的（比如全是 0 或全是 9）、flirting 和 positive 是否区分开了

### 常见模式速查

| 对话类型 | 典型分数分布 |
|----------|-------------|
| 教学/攻略（她教他撩妹） | info_exchange 7-8, opinion 7-8, invitation 5-8 |
| 暧昧互撩 | emotion_positive 6-8, flirt 6-9, question 4-6 |
| 创伤倾诉 | self_disclosure 7-9, emotion_negative 7-9, opinion 5-7 |
| 冷淡/拒绝 | emotion_negative 5-7, opinion 6-8, perfunctory 4-7, framing_boundary 3-5 |
| 日常闲聊（猫/吃/天气） | 各项 3-5，无极端值 |
| 事务交流（会议/酒店/技术） | info_exchange 5-8，其他标签大多 0-2 |
| 初次认识（问名字/哪里人） | question 4-6, info 3-5, positive 3-5 |

### 注意事项

1. **独立评分** — 每个标签是独立的。一段对话可以同时高信息交换和高情绪高昂（她兴奋地教他东西）
2. **微信语境** — 消息短、碎片化是常态。单字回复如果只是节奏快，不算敷衍
3. **表情包算情绪** — [破涕为笑] 算 positive，[微笑] 有时候阴阳不定需要看上下文
4. **语音/电话邀请算很强的 invitation** — "你方便吗接电话"、"打过来"是 7-8 分的行为
5. **「我」很主动不算她的** — 只看「她」的行为。如果「我」一直在撩她但她只是回复，flirt=0-2
6. **量化强度，不是二值** — 不要只打 0 或 9，中间分值大量使用。大部分标签在 3-6 之间

## 六、参考样本

以下是几个典型对话和我的标注：

### 样本 1：她教他撩妹（s_000170）

```
[我] 嗯呢
[她] 你咋私聊
...（她大段分析对方朋友圈、教怎么释放信号、找共同点）
[她] 你方便吗 接电话 我给你讲一下 好久没撩妹了
[她] 打过来 块 快
[她] 孺子可教
```

**标注：** `7|8|6|1|5|5|3|8|7|1`

解读：信息交换和观点表达极强（整段教学），正向情绪温和（一直在笑、鼓励），flirt 中等（教撩妹但不直接撩他），邀约极强（主动打电话），关系框架强（"哥"、"孺子可教"），基本无敷衍。

### 样本 2：冷淡拒绝（s_000127）

```
[她] 你这种性格 还不如多好好学习做点正事
[她] 你需要一个能提供情绪价值的人
[她] 我不是这样的人
[她] 你要别人给你提供
```

**标注：** `3|8|1|6|0|1|2|0|5|1`

解读：观点极强（在评判对方），负面情绪明显（居高临下的冷漠），无 flirt（她在划清界限），关系框架强（"我不是这样的人"就是在设边界）。

### 样本 3：热恋期撒娇（s_000181）

```
[她] 你亲我，我只会越来越热
[她] 等我学会了，可以做给你吃 [坏笑][坏笑][坏笑]
[她] 我好想你啊
```

**标注：** `3|2|8|1|9|2|5|5|2|0`

解读：正情绪极高、flirt 拉满、有自我表露、有邀约暗示。信息交换和观点表达低（恋爱中不需要这些）。

### 样本 4：初次认识（s_000279）

```
[她] 研究生哈哈哈 必须优秀的
[我] 诶 你本科在上海大学上的吗
[她] 不是哦 我在长沙毕业的，财经
[她] 你叫什么呀
[我] [REDACTED]
[她] 李慧雯 你玩那个目的是啥呀
```

**标注：** `5|4|4|1|3|6|5|2|1|1`

解读：互相问基础信息（info_exchange+question_asking 中等偏高），友好但不过度热情（positive=4），有点俏皮（flirt=3）。

## 七、标注工具

使用 `ml/scripts/label_batches.py` 管理标注流程，标注结果写入 `ml/dataset/annotations/annotations_XXX.jsonl`（XXX 为批次号）。

### 预览未标注样本

```bash
# 完整内容预览
python -X utf8 ml/scripts/read_for_label.py --batch 004 --offset 0 --count 20

# 快速预览（内容截断至 100 字）
python -X utf8 ml/scripts/label_batches.py --batch 004 --count 20
```

### 提交标注

```bash
# 单条
python -X utf8 ml/scripts/label_batches.py --batch 004 --submit "3|8|1|6|0|1|2|0|5|1"

# 批量
python -X utf8 ml/scripts/label_batches.py --batch 004 --submit "7|8|6|1|5|5|3|7|6|1" "3|8|1|6|0|1|2|0|5|1"

# 放弃（必须写明理由）
python -X utf8 ml/scripts/label_batches.py --batch 004 --submit "-1:乱码过多"
```

参数为 10 个 0-9 整数，用 `|` 分隔，顺序与上表一致。**Bash 下需加引号**，否则 `|` 会被解释为管道符。

### 查看进度

```bash
python -X utf8 ml/scripts/label_batches.py --progress
```
